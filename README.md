# 空调工作原理 3D 演示 · air-conditioner-3d

基于 [Three.js](https://threejs.org/) 的交互式分体空调制冷 / 制热原理可视化。精细建模的室内机、室外机和穿墙管路，配合制冷剂流动着色、空气粒子、压焓图，直观展示空调如何把热量从一侧"搬"到另一侧。

直接用浏览器打开 `index.html` 即可运行（需联网，从 CDN 加载 Three.js r160）。

## v1.1 亮点

### 精细建模（1 单位 = 10 cm，按真实比例）
- **室外机**：钣金外壳（风口、百叶、把手凹槽）、同心圆格栅 + 导风圈、三叶后掠轴流风扇 + 直流电机与支架、风机室 / 压缩机室隔板、后背与侧面防护网
  - **L 形双排翅片管换热器**：24 程 U 型铜管蛇形回路 + 约 200 片铝翅片，剖视时翅片"开窗"露出内部铜管
  - **滚动转子式压缩机**（可剖切）：外壳、定子、铜绕组、转子、曲轴、泵体，**滚动活塞偏心公转 + 滑片往复**实时动画
  - **四通换向阀**（可剖切）：阀体内滑块随模式切换左右移动，电磁先导阀线圈制热时通电发光
  - **电子膨胀阀**（针阀 + 步进线圈）、气液分离器、气 / 液截止阀、变频电控板（IPM 散热器、电容、继电器）
- **室内机**：弧形前面板、顶部进风格栅、过滤网、**三折式蒸发器**（30 程铜管 + 翅片）包围**贯流风扇**（34 片叶片、分段隔盘）、蜗壳、稳流舌、接水盘、上下摆动导风板 + 左右摆叶、温度显示屏
- **穿墙管路**：砖墙剖面 + PVC 护套、带保温棉的液管 / 气管、波纹排水管、电缆、管卡

### 原理可视化
- **制冷剂流动着色器**：所有铜管按制冷剂状态发光——高温高压蒸气（红）、高压液体（橙）、低温气液两相（蓝）、低压蒸气（青）；液体为平滑波纹、两相区有气泡、蒸气为快速流线
- **示踪粒子**：一小团制冷剂沿完整回路（包括压缩机、四通阀、膨胀阀内部）运动，与**压焓图（lg p–h，R32 近似饱和线）**上的状态点同步，实时显示温度、压力、焓值、干度
- **空气粒子**：室内空气经顶部格栅 → 过滤网 → 换热器（变色）→ 贯流风扇 → 导风板吹出；冷风下沉、热风上升（浮力）；室外空气从背面 / 侧面穿过盘管后被风扇旋转吹出
- **冷凝水**：制冷时蒸发器滴水入接水盘，排水管出口滴水
- **热量流向带**：直观表示热量 Q 从室内搬到室外（制热时反向）
- **制冷 ↔ 制热**：四通阀换向动画、制冷剂反向流动、换热器角色与标注互换、读数平滑过渡

- **自动导览**：9 段镜头 + 字幕讲解完整循环
- **视角预设**：总览、室外机、压缩机、四通阀、膨胀阀、室外换热器、风扇、穿墙管路、室内机、室内机剖面
- 悬停部件显示说明、点击聚焦；步骤卡片点击跳转；镜头跟随示踪粒子
- 快捷键：空格 暂停 · M 切换模式 · C 剖视 · T 导览 · 1–4 步骤 · Esc 回到总览

- PBR 材质 + RoomEnvironment 环境反射、ACES 色调映射、柔和阴影、4× MSAA

## 制冷循环原理简述

1. **压缩**（压缩机）— 低压蒸气被压缩成约 80 °C、2.8 MPa 的高温高压气体，唯一耗电做功环节
2. **冷凝**（制冷时在室外）— 高温气体向空气放热，在约 45 °C 冷凝成高压液体
3. **节流**（电子膨胀阀）— 压力骤降到约 1.0 MPa，部分闪发汽化，温度降到约 7 °C
4. **蒸发**（制冷时在室内）— 低温制冷剂沸腾，吸收室内空气热量，空气降温除湿

关键在于"压力改变沸点"：低压下 7 °C 就能沸腾吸热，高压下 45 °C 才冷凝放热。压缩机消耗少量电能，就能搬运 3～5 倍的热量（COP）。制热模式下四通阀换向，室内机与室外机角色互换。

> 读数与压焓图基于 R32 的近似饱和数据，用于教学示意。
