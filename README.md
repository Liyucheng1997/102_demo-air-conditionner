# 空调工作原理 3D 演示 · air-conditioner-3d

基于 [Three.js](https://threejs.org/) 的交互式空调制冷/制热原理可视化。通过剖视的室内机、室外机模型，配合制冷剂粒子流和空气换热动画，直观展示空调如何把热量从一侧"搬"到另一侧。

打开 `index.html` 即可运行（需联网，从 CDN 加载 Three.js）。

## 功能

- **剖视建模**：半透明外壳，可见内部
  - 室外机：同心圆格栅 + 轴流风扇、冷凝器盘管翅片、压缩机
  - 室内机：壁挂式，贯流风扇、蒸发器盘管、摆动导风板、顶部进风格栅
- **制冷剂闭环**：3D 走线，穿墙连接内外机，粒子颜色实时表示制冷剂四种状态（高温高压气 / 高压液 / 低温低压液 / 低压气）
- **空气换热动画**：常温空气被吸入 → 经盘管换热 → 吹出（冷风/热风），颜色渐变
- **制冷 ↔ 制热模式切换**：模拟四通阀换向，制冷剂反向流动、内外机角色互换、盘管与气流颜色对调、标签自动改名
- **实时读数面板**：高/低压侧压力、压缩机排气温度、室内送风温度、室外排风温度，随模式平滑变化
- **交互**：鼠标拖动旋转、滚轮缩放、右键平移；可暂停、调流速、分别开关各粒子系统；步骤卡片随循环自动高亮

## 制冷循环原理简述

1. **压缩机** — 把低压气体压缩成高温高压气体（唯一耗电做功环节）
2. **冷凝器**（制冷时在室外）— 高温气体向空气放热，冷凝成高压液体
3. **膨胀阀** — 高压液体骤然减压，温度急剧下降
4. **蒸发器**（制冷时在室内）— 低温液体吸收空气热量蒸发，使房间变凉

制热模式下四通阀换向，室内机与室外机的冷凝器/蒸发器角色互换，效果变为给室内供暖。
